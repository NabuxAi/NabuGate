## ۱. مرور کلی و معماری سیستم (Overview & Architecture)

سیستم مولتی‌ایجنت سئو در قالب خط‌لوله (Flow) اختصاصی در NabuGate عمل می‌کند. این سیستم شامل ۳ ساب‌ایجنت تخصصی است که به صورت زنجیره‌ای خروجی یکدیگر را تکمیل کرده و در نهایت یک گزارش جامع، نمره سئو و بسته کدهای اصلاحی آماده تزریق به وردپرس تولید می‌کنند.

```
                  +-----------------------------------+
                  |     درخواست کاربر / اسکریپت       |
                  | POST /v1/chat/completions         |
                  | model: "seo-audit-team"           |
                  +-----------------+-----------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
|                               NabuGate                                  |
|                                                                         |
|  گام ۱: [seo-content-auditor]                                            |
|  - آنالیز ساختار On-Page، هدینگ‌ها (H1-H4)، چگالی کلمات کلیدی، CWV      |
|                                                                         |
|  گام ۲: [seo-schema-engineer]                                           |
|  - استخراج خودکار پرسش/پاسخ‌ها، ویدیوها و تولید اسکیماهای JSON-LD       |
|                                                                         |
|  گام ۳: [seo-strategist-reviewer]                                       |
|  - محاسبه نمره ۱۰۰ امتیازی، استراتژی لینک‌سازی و تدوین گزارش نهایی       |
+-----------------------------------+-------------------------------------+
                                    |
                                    v
                  +-----------------------------------+
                  |      گزارش ساختاریافته Markdown   |
                  |    + کدهای JSON-LD آماده تزریق    |
                  +-----------------------------------+
```

## ۲. مشخصات ساب‌ایجنت‌ها (Agents Specification)

### ۲.۱. `agents/seo-content-auditor.yaml`
* **نام ایجنت:** `seo-content-auditor`
* **مدل پیش‌فرض:** `nabu-smart`
* **تنظیمات سمپلینگ:** `temperature: 0.3`, `max_tokens: 4096`
* **شرح وظایف:**
  1. بررسی سلسله‌مراتب تیترها (`H1` تا `H4`) و یکپارچگی منطقی.
  2. بررسی تناسب عنوان (`Title`) و توضیحات متا (`Meta Description`) از لحاظ تعداد کاراکتر و جذابیت کلیک.
  3. ارزیابی چگالی و جای‌گیری کلمه کلیدی در پاراگراف اول، هدینگ‌ها و بدنه متن.
  4. بررسی خوانایی، ساختار پاراگراف‌ها، وجود فهرست مطالب و تجربه کاربری محتوا.
  5. شناسایی فرصت‌های بهبود تصاویر (بررسی تگ‌های `alt` و ویژگی‌های بهینه‌سازی سرعت).

### ۲.۲. `agents/seo-schema-engineer.yaml`
* **نام ایجنت:** `seo-schema-engineer`
* **مدل پیش‌فرض:** `nabu-smart`
* **تنظیمات سمپلینگ:** `temperature: 0.2`, `max_tokens: 4096`
* **شرح وظایف:**
  1. استخراج تمام پرسش‌ها و پاسخ‌های موجود در متن و تبدیل آن‌ها به ساختار معتبر `FAQPage` بر اساس استانداردهای Schema.org.
  2. شناسایی ویدیوها (امبد یا لینک‌های یوتیوب/آپارات) و ساخت اسکیمای کامل `VideoObject` با فیلدهای عنوان، تصویر شاخص، تاریخ و URL.
  3. تولید اسکیمای `Article` / `BlogPosting` استاندارد با فرمت صحیح زبان فارسی.
  4. اطمینان از خروجی معتبر JSON-LD درون تگ `<script type="application/ld+json">`.

### ۲.۳. `agents/seo-strategist-reviewer.yaml`
* **نام ایجنت:** `seo-strategist-reviewer`
* **مدل پیش‌فرض:** `nabu-smart`
* **تنظیمات سمپلینگ:** `temperature: 0.4`, `max_tokens: 4096`
* **شرح وظایف:**
  1. تجمیع تحلیل‌های گام ۱ و ۲ و محاسبه نمره دقیق سئو از ۰ تا ۱۰۰ بر اساس مدل ۲۵ فاکتوره.
  2. پیشنهاد کلمات کلیدی مکمل (Secondary & LSI Keywords) برای رتبه‌گیری در سرچ کنسول.
  3. پیشنهاد لینک‌سازی داخلی متقابل بین این مقاله و سایر دسته‌ها و مقالات سایت مستر چت‌جی‌پی.
  4. ارائه خروجی نهایی در قالب گزارش جامع Markdown همراه با چک‌لیست اولویت‌بندی‌شده (فوری / میان‌مدت).

## ۳. تعریف پایپ‌لاین چندمرحله‌ای (Flow Specification)

فایل: `flows/seo-audit-team.yaml`

```yaml
name: seo-audit-team
description: "تیم مولتی‌ایجنت سئو NabuGate: بررسی عمیق محتوا، تولید داده‌های ساختاریافته و رتبه‌بندی جامع مقالات"

steps:
  - agent: seo-content-auditor
    label: "تحلیل محتوا و سئوی درون‌صفحه‌ای"

  - agent: seo-schema-engineer
    label: "تولید و اعتبارسنجی اسکیماهای JSON-LD"
    input: |
      محتوای مقاله ارائه‌شده:
      {{input}}

      تحلیل ساختاری و محتوایی انجام‌شده:
      {{previous}}

      بر اساس متن مقاله و نکات ساختاری، اسکیماهای کامل JSON-LD شامل FAQPage و VideoObject (در صورت وجود ویدیو) و Article را به صورت تمیز و بدون خطای نگارشی ایجاد کن.

  - agent: seo-strategist-reviewer
    label: "رتبه‌بندی نهایی سئو و تولید گزارش راهبردی"
    input: |
      ورودی اصلی مقاله:
      {{input}}

      اسکیماها و تحلیل‌های مراحل قبل:
      {{previous}}

      یک گزارش جامع، شفاف و کاربردی در قالب Markdown شامل نمره سئو (۰ تا ۱۰۰)، جدول نقاط قوت و ضعف، کلمات کلیدی پیشنهادی و کدهای آماده برای وردپرس تولید کن.
```

## ۴. مدل محاسبه نمره سئو (SEO Scoring Model)

| شاخص ارزیابی | وزن نمره | معیارهای کلیدی |
| :--- | :---: | :--- |
| **ساختار و هدینگ‌ها** | ۲۰ نمره | وجود یک H1، ساختار درختی مرتب H2/H3، فهرست مطالب |
| **محتوا و کلمات کلیدی** | ۲۵ نمره | چگالی طبیعی (۱-۲.۵٪)، وجود کلمه در تیتر و پاراگراف اول، جامعیت متن |
| **داده‌های ساختاریافته (اسکیما)** | ۲۰ نمره | اسکیمای FAQPage، اسکیمای VideoObject و Article بدون ارور |
| **لینک‌سازی و کلاسترینگ** | ۱۵ نمره | لینک‌های داخلی به مقالات مرتبط، انکرتکست‌های توصیفی، عدم وجود لینک شکسته |
| **رسانه و شاخص‌های سرعت** | ۲۰ نمره | تگ Alt برای تمام تصاویر، بهینه‌سازی امبدها، خوانایی در موبایل |

## ۵. تست و اعتبارسنجی (Testing & Verification)

1. **اعتبارسنجی پیکربندی:** اطمینان از لود صحیح فایل‌های YAML در NabuGate با اجرای تست محلی یا بررسی `GET /v1/models`.
2. **تست روی مقاله واقعی:** اجرای Flow برای مقاله Hell Grind (`post-13300`) و بررسی صحت گزارش و اسکیماهای خروجی.
3. **اعتبارسنجی خروجی اسکیما:** بررسی سازگاری JSON-LD تولیدی با ابزار Rich Results Test گوگل.
